## Descripción del proyecto

Este proyecto aplica técnicas de ciencia de datos y
Machine Learning para estudiar el desempeño académico
de estudiantes colombianos en las pruebas Saber 11.

Se utiliza información oficial del portal datos.gov.co,
correspondiente al periodo 2024-2.

## Problemática

En Colombia existen diferencias en el desempeño académico
que pueden estar relacionadas con las condiciones
socioeconómicas, familiares y educativas.

El proyecto busca analizar estas relaciones y desarrollar
modelos predictivos que permitan estudiar el desempeño
académico a partir de características de los estudiantes
y su entorno.

## Objetivo general

Analizar factores asociados al desempeño académico
en las pruebas Saber 11 y desarrollar modelos de
Machine Learning para predecir sus resultados.

## Objetivos específicos

1. Explorar las características del dataset.
2. Identificar valores faltantes e inconsistencias.
3. Preparar las variables para el entrenamiento.
4. Entrenar y comparar al menos tres modelos.
5. Evaluar los modelos mediante métricas apropiadas.
6. Seleccionar y justificar el mejor modelo.
7. Desarrollar una aplicación interactiva en Streamlit.

## Fuente de datos

Portal: Datos Abiertos de Colombia

Dataset: Saber 11, periodo 2024-2.

Enlace:
https://www.datos.gov.co/resource/rnvb-vnyh.csv

Muestra de trabajo: 10.000 registros.
